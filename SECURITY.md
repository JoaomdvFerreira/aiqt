# Security Policy

## Reporting a vulnerability

When this repository becomes public, report vulnerabilities privately through GitHub Private Vulnerability Reporting. Do **not** use public GitHub Issues, Pull Requests, or Discussions for sensitive reports.

Include a clear description, affected version or commit, reproduction steps or proof of concept where safe, impact assessment, and any suggested mitigation. Do not include credentials, tokens, or unnecessary personal data.

AIQT is maintained without a dedicated security on-call rotation. Reports will be acknowledged and investigated on a best-effort basis, typically in days rather than hours; no SLA or bounty program is promised.

Please allow a reasonable coordinated-disclosure period before public disclosure.

## Scope

AIQT's source, dependencies, CI/release tooling, and documented integration boundaries are in scope. Third-party services chosen by an operator are not automatically in scope.

## Supported versions

AIQT is pre-1.0. The current `main` line is the supported line; older versions do not have a backport commitment.
